# MiraiPanel-LCD

Firmware für das MiraiPanel — ESP32-P4-Touchdisplay für
Loxone-Hausautomation.

Teil der [MiraiPanel](https://github.com/Holzmusik/MiraiPanel)-Projektfamilie
— siehe dort für die Gesamtübersicht, sowie
[LoxBerry-Plugin-MiraiPanel](https://github.com/Holzmusik/LoxBerry-Plugin-MiraiPanel)
(Loxone-Bridge) und
[MiraiPanel-Hardware](https://github.com/Holzmusik/MiraiPanel-Hardware)
(PCB/Gehäuse-Fertigungsdaten).

## Status

🚧 Noch im Aufbau — die Firmware wird aktuell noch getestet und um weitere
Funktionen ergänzt, bevor der Quellcode hier veröffentlicht wird.
